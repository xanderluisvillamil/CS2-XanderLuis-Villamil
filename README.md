# Travel Fare Calculator


## Description 
This program calculates the travel fare based on distance and the number of passengers.


## Version 2 - Original code with input validation


- Input: Accepts a passenger's name, distance in kilometers, and number of passengers.
-Process: Validates inputs using while loops and handles data type conversion errors using try-except blocks before calculating the total fare.
- Output: Validated passenger name and total fare in PHP rounded to two decimal places.
- Includes error trapping to prevent the program from crashing when invalid characters or symbols are entered.
